# Resumir continuidad

1. Agrupa por estado. Usa `CONFIRMADO` para hechos con evidencia directa, `REPORTADO` para afirmaciones sin esa evidencia y `PENDIENTE` para trabajo o verificaciones abiertas. Conserva el alcance real de cada prueba.
2. Para cada dato que cambie el siguiente paso, conserva fuente, fecha y condición relevante. Cuando dos fuentes discrepen, indica cuál verificaste y qué sigue sin resolverse.
3. Deja un siguiente paso concreto con la verificación y el permiso que requiera. Elimina secretos y fragmentos de registros que no aporten a la decisión.

Si piden un mensaje de traspaso, entrega el borrador listo para revisar. El envío requiere autorización independiente.
